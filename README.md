# 日本の名字シミュレーション

上位10姓と`その他`を母集団にした、父方の名字を継承する中立モデルです。

```bash
npm test
npm run simulate -- --end-year 2325 --output results/2325.json
npm run live
```

`--seed`を省略すると、実行ごとに新しい乱数seedを生成するため、異なる試行になります。表示されたseedを指定すれば、その試行を再現できます。

```bash
# 毎回異なる試行。表示されたseedを控える
npm run simulate -- --end-year 3025

# seedを使って同じ試行を再現する
npm run simulate -- --end-year 3025 --seed 20261107
```

`--generation-years`の既定値は30年で、指定した終了年は必ず最終世代として計算・表示します。表示表はその時点の推定人数の降順です。

## ライブシミュレーション

```bash
# 1秒で1年進める（既定値）。qで終了
npm run live

# 乱数の再現、または代表エージェントの倍率を変更
npm run live -- --seed 20261107 --scale 1000 --years-per-second 1
```

`npm run live`は個体ではなく、既定で**1エージェント=100人**の代表エージェント約123万人を追跡します。以前の既定値で実行したい場合は`--scale 1000`を指定してください。初期年齢構成は0〜14歳、15〜64歳、65〜74歳、75〜84歳、85歳以上の5区分で設定し、各年に現在の年齢で死亡を判定した後、生存者の年齢加算、未婚者の結婚、既婚女性の出生を処理します。結婚時には女性が男性の名字に変わり、子は父方の名字を継承します。

ライブ版は、総エネルギーを一定の100として人口全員に均等に分配する仮説を使います。1人あたりのエネルギーは初期値を1とした相対値で、出生判定直前の人口から`初期人口 ÷ 現在人口`として求めます。出生確率の倍率は`min(2, 1 + 0.5 × (1人あたりのエネルギー - 1))`です。例えば人口が初期の半分なら1.5倍、3分の1以下なら上限の2倍になります。人口が初期より増えると倍率は1を下回ります。画面には現在人口から計算した相対値と倍率を表示します。

出生確率の基準値は20〜29歳の既婚女性が年15%、30〜39歳が年8.75%で、この倍率を掛けます。基準値は以前の固定確率モデルで2050年と2070年の人口アンカーに近づくよう調整したもので、実測値ではありません。新モデルで人口アンカーとの一致を保証するものではありません。エネルギーと出生率の関係も検証済みの事実ではなく、将来を予測するためではなく仮説を試すための設定です。人口は結婚、出生、死亡の結果として変化し、seedや代表エージェントの倍率で結果が変わります。人口が少なくなるとエージェントの粒度の影響も大きくなります。

`space`で一時停止、右矢印で1年送り、`+`/`-`で速度を変更できます。人口が0になると、その年の結果を表示して自動終了します。名字別人数は代表エージェント数に倍率を掛けた推定値です。

## データ

- `data/surnames.json`は、名字由来netの2025年10月時点の全国順位・推定人数を記録しています。名字由来netは政府発表統計および全国電話帳データから独自算出した値であり、戸籍の全数統計ではありません。出典: [2026年ユーザーが選んだベスト・オブ・名字ランキング](https://myoji-yurai.net/rareNameRanking.htm?rareNameKind=BestOfMyoji2026)、[名字検索](https://myoji-yurai.net/)。
- 2025年、2050年、2070年の人口アンカーは、国立社会保障・人口問題研究所の[日本の将来推計人口（令和5年推計）](https://www.ipss.go.jp/pp-zenkoku/j/zenkoku2023/db_zenkoku2023/db_zenkoku2023gaiyo.html)の出生中位・死亡中位の総人口推計です。

世代単位の`npm run simulate`では、2070年以降は2050〜2070年の年率人口変化を指数的に延長します。この部分は公的推計ではなく、数百年先を計算するための仮定です。ライブ版はこの延長推計には従いません。

## モデル上の仮定と限界

- 夫婦別姓は扱わず、子は父方の名字を継承します。
- 各名字の出生率・死亡率は同一です。そのため、名字ごとの比率変化は確率的なゆらぎだけです。
- `その他`は複数の名字をまとめたカテゴリなので、希少名字の消滅数や新しい名字の発生は推定できません。
- 移民による人口変化は人口推計に含まれますが、新しい名字の流入はモデル化していません。
